Production Deployment Guide · fc.texasdrill.me

Production architecture, Nginx reverse proxy, systemd services, and one-command deployment

⚡ Quick Deploy Commands

# 1. Run automated installer on Ubuntu / Debian VPS: chmod +x deploy.sh ./deploy.sh # 2. Or run manually with PM2: pm2 start ecosystem.config.js pm2 save # 3. Or run with Systemd: sudo systemctl enable fc-betting sudo systemctl start fc-betting

🌐 Nginx Domain Configuration (fc.texasdrill.me)

server { server_name fc.texasdrill.me; listen 80; location / { proxy_pass http://127.0.0.1:8000; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; } }

To issue free SSL certificate: sudo certbot --nginx -d fc.texasdrill.me
